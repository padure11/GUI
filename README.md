# CodeBots: Factory Breakout

CodeBots: Factory Breakout is a 3D cooperative puzzle game developed in Unity using C#.

The game combines puzzle solving with programming concepts. Two players control robots inside a factory and must cooperate to complete each level.

Instead of directly controlling the robots, players write commands in an in-game code editor. The written code is parsed and executed by the game, allowing the robots to interact with the environment and solve puzzles.

## Core Gameplay

Players program their robots using commands such as:

- `moveForward()`
- `moveBack()`
- `turnLeft()`
- `turnRight()`
- `jump()`
- `push()`
- `pull()`
- `press()`
- `wait()`

The programming system also supports repeated commands and user-defined functions.

Both players submit their code and the robots execute their instructions together, requiring coordination to solve cooperative puzzles.

## Features

- 3D cooperative puzzle gameplay
- In-game code editor

- Command execution system
- User-defined functions
- Repeat structures
- Robot movement and interaction mechanics
- Pushable objects and interactive buttons
- Multiplayer synchronization
- Level progression system

## Educational Concept

The project is designed to introduce programming concepts through interactive gameplay.

Players learn to think in terms of ordered instructions, functions and repeated actions while solving puzzles together.
